# Live Example Review Plan

## Overview
This document outlines the systematic review process for all Live Example screens across the 5 tone spectrums. We'll review each spectrum at key slider positions to ensure the UI states and copy accurately reflect the tone characteristics.

## Review Process
For each screen, we will:
1. **View** the live example at the specified slider position
2. **Discuss** whether the UI state choice and copy match the tone
3. **Evaluate** linguistic device usage and UX writing quality
4. **Edit** if needed to better reflect the spectrum characteristics
5. **Confirm** and move to the next position

## Review Checklist per Screen
- [ ] Appropriate UI state for tone (celebration, onboarding, confirmation, error, urgent)
- [ ] Copy reflects sub-dimension characteristics
- [ ] Linguistic devices properly applied
- [ ] Button labels match tone
- [ ] Overall user experience feels authentic
- [ ] Implement any relevant changes to spectrum sub-dimensions and devices
